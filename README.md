# Aethis

**GPU-Accelerated Guitar Processor**

Aethis is a guitar amp simulator and multi-effects processor featuring neural amp modeling, a 4-voice multivoicer with MIDI harmony, and a complete effects chain. Available as Standalone, VST3, and Audio Unit for macOS and Windows.

**Website:** [aethis.agastyajindal.com](https://aethis.agastyajindal.com)

---

## Features

- **Three Amp Models** — Noctis (high gain), Ember (modern rock), Lumina (clean)
- **Dual Cabinet System** — Two independent cabs with 6 mic types, draggable mic position, stereo panning
- **4-Voice Multivoicer** — Polyphonic pitch shifting, MIDI chord-following harmonies, scale quantization, stereo width control
- **Bloom Tab** — Pitch-aware Contour EQ, polyphonic Octaver, tuned Bitcrush
- **Parametric EQ** — 9 draggable bands with real-time spectrum analyzer, 24 dB/oct HP/LP filters
- **Pre-FX Pedals** — Boost, Drive (tube saturation), Compressor, Noise Gate
- **Post-FX** — Chorus, Delay (with tempo sync), Reverb with shimmer
- **Global Transpose** — Digital capo / drop tuning (-12 to +12 semitones)
- **Built-In Tuner** — Chromatic tuner with configurable A4 reference (400-480 Hz)
